# ShoppyGlobe Backend API

ShoppyGlobe is an e-commerce backend application developed using Node.js, Express.js, and MongoDB.  
This project is created as part of an academic assignment to build REST APIs for an e-commerce platform.

The backend provides APIs for user authentication, product management, and shopping cart functionality, along with proper error handling and validation.



## Technologies Used

- Node.js
- Express.js
- MongoDB (MongoDB Atlas)
- Mongoose
- JSON Web Token (JWT)
- Thunder Client (for API testing)


## API Testing

All APIs are tested using Thunder Client extension in VS Code.

## How to Run the Project

Install dependencies:
npm install

Start the server:
npm start

Server will run on:
http://localhost:3001
